    ```python
    from __future__ import annotations
    import hashlib
    import frontmatter as fm

    def normalize_body(body: str) -> str:
        """Per D-14: CRLF->LF, rstrip each line, single trailing newline."""
        lines = body.replace("\r\n", "\n").split("\n")
        stripped = [ln.rstrip() for ln in lines]
        text = "\n".join(stripped).rstrip("\n") + "\n"
        return text

    def compute_content_hash(path: str) -> str:
        """Per D-13: sha256 of frontmatter-stripped, normalized body. 64-char lowercase hex."""
        post = fm.load(path)
        return hashlib.sha256(normalize_body(post.content).encode("utf-8")).hexdigest()
    ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| shell → env var | `DATABASE_URL`, `POSTGRES_PASSWORD` loaded from `.env` — never hardcoded |
| test process → docker | testcontainers binds to ephemeral port; never 0.0.0.0 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information disclosure | `.env.example` with `DATABASE_URL` containing `${POSTGRES_PASSWORD}` | mitigate | `.env.example` uses the shell-expansion form `${POSTGRES_PASSWORD}` only — no literal secret. `.env` remains gitignored (Phase 1 OPS-06). |
| T-02-02 | Information disclosure | Log output may contain DATABASE_URL with password | mitigate | Alembic logger is configured at WARN; SQLAlchemy engine is created with default `echo=False`. No code path logs `os.environ["DATABASE_URL"]`. |
| T-02-03 | Tampering | Migration applied to wrong DB | mitigate | `src/db/migrations/env.py` uses `os.environ["DATABASE_URL"]` (fail-fast KeyError if unset — no hardcoded default). CI/tests must set it explicitly via testcontainers fixture. |
| T-02-04 | Information disclosure | Test container leaking on host network | mitigate | `testcontainers.postgres.PostgresContainer` binds to an ephemeral localhost port and destroys on `__exit__`. Image reused from docker-compose (same hash). |
| T-02-05 | Tampering | Content-hash collision attack via sha256 | accept | sha256 is collision-resistant (2^128 work factor). Content-hash is used for dedup/addressing, NOT as a security primitive. Documented in `src/shared/content_hash.py` docstring. |
</threat_model>
