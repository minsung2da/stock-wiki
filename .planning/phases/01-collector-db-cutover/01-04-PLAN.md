<objective>
Cut the KRX collector from `vault/raw/krx/*.md` writes to direct INSERTs into
the `ohlcv` Postgres table.

This is the second-simplest collector (RESEARCH.md Q8). It adds FK resolution
to `entities` (already battle-tested via `resolve_entity` — ENT-01/ENT-02)
and the T+2 `short_volume` fill-in pattern that Wave 2 collectors will not
need but is documented in RESEARCH.md Pitfall 4.

Builds directly on the `db_writer` shape established by 01-03 (macro), but
with classification at the per-ticker level (one row per ticker, not many),
so the API shape differs slightly (returns a single outcome label, not counts).

Purpose:
- SC-2 (UPSERT dedup pattern for krx)
- SC-5 (DB-based test assertions for tests/collectors/krx/)
- Establishes the FK-resolution pattern that 01-05 (kind) and 01-07 (dart)
  reuse

- `src/collectors/krx/db_writer.py` with `upsert_ohlcv`
- `collect_krx` body switched from `writer.write_krx_doc` to db_writer
- Tests fully ported to DB assertions

    `db_writer.upsert_ohlcv` contract:

    ```python
    def upsert_ohlcv(
        engine: Engine,
        *,
        ticker: str,
        trade_date: date,
        corp_code: str | None,
        ohlcv_row: dict,   # {"open": Decimal|float, "high": ..., "low": ..., "close": ..., "volume": int}
        flow_row: dict | None = None,  # {"trading_value": int, "foreign_net": int, "inst_net": int, "retail_net": int}
        short_row: dict | None = None,  # {"short_volume": int|None, "short_balance": int|None}
    ) -> Literal["inserted", "updated", "skipped"]:
        """
        Returns:
          "inserted" — fresh row inserted
          "updated"  — existing row, at least one value changed (including T+2 short fill-in)
          "skipped"  — existing row, all incoming values identical
        """
    ```

    Implementation:

    1. Validate `ticker` is `^[0-9]{6}$` (raise ValueError).
    2. `flow_row` and `short_row` can be None — the columns just stay NULL.
    3. The COALESCE pattern for T+2 short fill-in:
       ```sql
       INSERT INTO ohlcv (ticker, trade_date, open, high, low, close, volume,
                          trading_value, foreign_net, inst_net, retail_net,
                          short_volume, short_balance, corp_code, fetched_at)
       VALUES (:ticker, :trade_date, :open, :high, :low, :close, :volume,
               :trading_value, :foreign_net, :inst_net, :retail_net,
               :short_volume, :short_balance, :corp_code, now())
       ON CONFLICT (ticker, trade_date) DO UPDATE SET
         open = EXCLUDED.open,
         high = EXCLUDED.high,
         low  = EXCLUDED.low,
         close = EXCLUDED.close,
         volume = EXCLUDED.volume,
         trading_value = EXCLUDED.trading_value,
         foreign_net   = EXCLUDED.foreign_net,
         inst_net      = EXCLUDED.inst_net,
         retail_net    = EXCLUDED.retail_net,
         short_volume  = COALESCE(EXCLUDED.short_volume,  ohlcv.short_volume),
         short_balance = COALESCE(EXCLUDED.short_balance, ohlcv.short_balance),
         corp_code     = COALESCE(EXCLUDED.corp_code,     ohlcv.corp_code),
         fetched_at    = now()
       ```
       Note `COALESCE` ONLY on `short_volume/short_balance/corp_code` —
       OHLCV values must be overwritten (price corrections do happen).

    4. To distinguish inserted vs updated vs skipped, do a "load → compare →
       upsert" pattern like 01-03 macro:
       ```python
       with engine.begin() as conn:
           existing = conn.execute(text("""
               SELECT open, high, low, close, volume, trading_value,
                      foreign_net, inst_net, retail_net,
                      short_volume, short_balance
               FROM ohlcv WHERE ticker=:t AND trade_date=:d
           """), {"t": ticker, "d": trade_date}).first()
           if existing is None:
               outcome = "inserted"
           else:
               # Compare each non-null incoming value with existing.
               # Track whether any column would actually change.
               changed = any of (incoming open/high/low/close/volume/flow/short
                                 differs from existing AND incoming is not None)
               outcome = "updated" if changed else "skipped"
           if outcome == "skipped":
               return outcome
           conn.execute(upsert_sql, params)
       return outcome
       ```

            # do the same here.
            ohlcv_row = {
                "open":   ohlcv_df.iloc[0]["open"],
                "high":   ohlcv_df.iloc[0]["high"],
                "low":    ohlcv_df.iloc[0]["low"],
                "close":  ohlcv_df.iloc[0]["close"],
                "volume": int(ohlcv_df.iloc[0]["volume"]),
            }
            # Same column-name discipline for flow/short — see fetcher.py
            outcome = db_writer.upsert_ohlcv(
                engine,
                ticker=ticker,
                trade_date=date.fromisoformat(date_iso),
                corp_code=ent.corp_code,
                ohlcv_row=ohlcv_row,
                flow_row=flow_dict,
                short_row=short_dict,
            )
            if outcome == "inserted":
                stats["inserted"] += 1
            elif outcome == "updated":
                stats["updated"] += 1
            else:
