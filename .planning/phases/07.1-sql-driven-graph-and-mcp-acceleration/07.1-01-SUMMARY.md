# Phase 07.1 Plan 01: SQL → graphify Extraction Adapter — Summary

and returns a `graphify.build.build_from_json`-compatible
`{nodes, edges, input_tokens=0, output_tokens=0}` dict — the data plane that lets
Plan 02 snapshot and Plan 03 MCP cache bypass graphify's empty-on-markdown
`detect/extract` path (Phase 7 gap-1).

## Deviations from Plan

**1. [Rule 1 — Bug] Edge keys `source`/`target`, not `src`/`dst`**
- **Found during:** Task 1 (graphify contract inspection step)
- **Issue:** Plan's `<interfaces>` sketch used `{"src": ..., "dst": ...}`. Inspecting
  `graphify.build.build_from_json` revealed it consumes `source`/`target` (or
  `from`/`to` aliased), and silently drops edges that reference unknown fields.
- **Fix:** Adapter emits `source`/`target` directly. Plan steps that referred to
  `src`/`dst` were treated as semantic placeholders, not literal contract.
- **Files modified:** `src/graph/sql_to_graph.py`, `tests/graph/test_sql_to_graph.py`
- **Commit:** `5a1ba22`

**2. [Rule 2 — Critical functionality] `source_file` over legacy `source`**
- **Found during:** Task 1 contract verification
- **Issue:** Plan's <interfaces> showed `source_file`, but `build_from_json` body
  contains an explicit warning when nodes use legacy `source` — would have polluted
  Plan 02 snapshot stderr at scale.
- **Fix:** Adapter emits `source_file` from the start; tests assert this key.
- **Commit:** `5a1ba22`

## Key Interfaces for Downstream Plans (02, 03)

```python
from graph.sql_to_graph import build_extraction

# Plan 02 (snapshot.py rewrite)
extraction = build_extraction(engine)        # ≤ 3 SELECTs, no LLM
G = graphify.build.build_from_json(extraction, directed=True)
# G is a populated nx.DiGraph carrying tag/edge_type/label as attributes

# Plan 03 (MCP graph_cache)
extraction = build_extraction(engine)
cache = nx.DiGraph()                          # warmed once at server start
for n in extraction["nodes"]:
    cache.add_node(n["id"], **{k: v for k, v in n.items() if k != "id"})
for e in extraction["edges"]:
    cache.add_edge(e["source"], e["target"], **{k: v for k, v in e.items()
                                                  if k not in {"source", "target"}})
```

The extraction dict is also JSON-serialisable as-is — Plan 02 can persist it to disk
verbatim and `build_from_json` will read it back (the round-trip is part of the test
suite).
