Subprocess shape (RESEARCH Pattern 1 — live-verified):
```
claude -p "<instruction>" --output-format json --model sonnet
       --json-schema '<INLINE json string>' --strict-mcp-config
       --append-system-prompt "<role system prompt>"
# evidence via STDIN (communicate(bundle.encode())), NOT argv (Windows 32K + injection)
```
JSON envelope keys (read `structured_output`, NOT `result`):
```
is_error, structured_output, result, total_cost_usd, duration_ms, duration_api_ms,
usage{input_tokens,output_tokens,cache_creation_input_tokens,cache_read_input_tokens},
modelUsage{"claude-sonnet-4-6":{inputTokens,outputTokens,costUSD,...}}
```
Forbidden: `--bare` (forces ANTHROPIC_API_KEY → breaks Max-only Veto). No `shell=True`.

Seam contract this plan defines (consumed by the runner in Wave 3):
```python
class RoleResult(BaseModel):  # extra="forbid"
    role: str; data: dict; cost: dict   # data = structured_output; cost = envelope subset
class DebateBackend(Protocol):
    async def run(self, role: str, instruction: str, system_prompt: str, schema: dict, evidence_stdin: str, *, timeout_s: float = 180.0) -> RoleResult: ...
```

Analog for retry/error/seam structure: src/collectors/dart/fetcher.py (PATTERNS lines 97-153).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| runner → claude CLI subprocess | evidence (untrusted narrative) crosses into a spawned process |
| process auth → Max OAuth | the CLI's OAuth token must never be replaced by an API key or logged |
| CLI JSON envelope → cost sink | the envelope is trusted CLI output; only the cost subset is recorded |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-13 | Tampering / EoP | shell/command injection via evidence in argv | mitigate | `create_subprocess_exec` (argv list, no `shell=True`) + evidence on stdin; never interpolate narrative into the command |
| T-04-14 | Information disclosure | API-key / OAuth-token exposure | mitigate | Max OAuth only; NEVER `--bare`, never set/read `ANTHROPIC_API_KEY`, never log the auth token; import guard keeps anthropic/openai out of src/analysis |
| T-04-15 | DoS | hung / cold-cache sub-agent call | mitigate | per-call `asyncio.wait_for` wall-clock timeout (~180s) + one retry on retryable category, then fail loudly |
| T-04-16 | Repudiation | unaccounted cost/quota | mitigate | `capture_cost` records the envelope cost subset per call → SC#7 structured stderr for Phase 9 |
| T-04-SC | Tampering | npm/pip installs | accept | No installs in Phase 4 (RESEARCH audit: zero new deps; `claude` CLI already on PATH) — N/A |
</threat_model>
