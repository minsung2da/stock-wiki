## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| query text → embedding/tokenizer/SQL | untrusted search query |
| narrative snippet → downstream LLM | retrieved body may carry injection |
| tool registry → MCP client | only the 10 locked tools may be exposed |
| stdio stream → Claude Code | protocol integrity (no stray stdout) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-veto6 | Tampering | hybrid_search source_filter | mitigate | reject ohlcv/macro_series/decision_cards → InvalidArgument; SQL touches only filings/news/notes (SC#4) |
| T-prompt-inj | Tampering (downstream LLM) | hybrid_search snippet | mitigate | snippet WRAP+FLAG via injection.wrap_untrusted/detect (D-03); no body_md (D-02) |
| T-SQL-escape | Elevation of Privilege | tool registry / retrieval SQL | mitigate | SC#3 registry guard enforced (==10 names) + AST no-fstring-SQL; retrieval SQL = module-level text() constants |
| T-stdout-corrupt | Denial of Service | __main__ stdio | mitigate | all logging to stderr; only FastMCP writes protocol stdout (Pitfall 7) |
| T-03-token-DoS | Denial of Service | hybrid_search response | mitigate | D-04 default top-10; references-not-blobs (D-02) |
| T-db-fault | Information Disclosure | _check_db_connection / query failure | mitigate | DataBackendError (specific) + FastMCP mask_error_details for unexpected bugs |
