| existing body_md → embedding pipeline | narrative text fed to bge-m3 / mecab |
| tool source files → CI guard | static assertion that no arbitrary-SQL escape hatch exists |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-SQL-escape | Elevation of Privilege | any future `run_sql`-style tool | mitigate | SC#3 guard: registry==10 locked names + AST rejects non-constant `text()` args (test_no_run_sql_guard.py) |
| T-veto6 | Tampering | backfill / notes-ingest SQL | mitigate | parameterized `text()` constants only; numeric tables (ohlcv/macro) NOT embedded; only narrative body embedded |
| T-03-03 | Tampering | notes ingest content_hash dedup | mitigate | sha256 content_hash + `ON CONFLICT (path) DO UPDATE` (idempotent; primitive dedup, not security) |
| T-03-04 | Information Disclosure | notes are personal (gitignored) | accept | notes loaded to LOCAL Postgres only, never committed (D-05); single-user local DB |
</threat_model>
