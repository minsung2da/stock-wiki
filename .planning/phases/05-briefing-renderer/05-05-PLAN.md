<objective>
Build the weekly roll-up: aggregate the week's <=7 daily briefings into a per-ticker NET-change
digest, PRE-MATERIALIZE the entries into a `report_type='weekly_briefing'` row, and record
coverage. Reads never recompute — `get_briefing(weekly)` just SELECTs the stored row (SC#4). A
genuine digest, not a 7-day union: intra-week flip-flops net to no-change (D-07), and missing
dailies are rolled up best-effort with a coverage count (D-08).

Purpose: SC#4 + D-07/D-08. The weekly reuses the daily's locked entries[] schema (stance +
conviction per entry) and the D-01 sort key — everything else is deterministic dict aggregation.
Output: src/briefing/weekly.py::generate_weekly_briefing.
</objective>
