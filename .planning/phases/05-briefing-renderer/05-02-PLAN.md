Build the typed store surface for briefing rows — the ONLY way app code touches the new
`report_type` rows (Veto #7, no run_sql). Adds a separate `BriefingRow` Pydantic model (NOT a

`get_daily_briefings_in_range` helper (the weekly's source). Closes the two store gaps
05-RESEARCH flagged: no enumeration helper, and `invalidate()` records no timestamp.

emit no `text()` of their own. Also stands up the shared test fixture (>=11 seeded tickers)
that the daily truncation/priority tests need.
Output: BriefingRow model, 4 new store helpers + invalidate stamp, multi-entity test conftest.
