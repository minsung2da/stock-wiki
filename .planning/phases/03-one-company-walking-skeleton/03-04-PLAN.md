<objective>
Compose the Wave 2 leaf utilities (Plan 02 + Plan 03) into the end-to-end ingest worker. Reads `vault/raw/**/*.md`, parses sections, chunks, embeds, tokenizes for BM25, writes into `documents` + `chunks` tables, and updates `ingest_state` frontmatter back into the vault file. Atomically per-document, resuming on failure.

Purpose: Fulfills INGEST-01 (content-hash dedup) and STORE-06 (three-zone frontmatter integrity). Produces the populated DB that Plan 05's MCP search queries.
Output: worker.py + 10+ integration tests using testcontainers Postgres + real bge-m3 model (slow marker for full path) + fast dummy-tokenizer variant for CI.

| ingest → vault file writeback | Only zone 2 (ingest_state) mutated; zones 1 and 3 are byte-preserved via Pydantic roundtrip |
