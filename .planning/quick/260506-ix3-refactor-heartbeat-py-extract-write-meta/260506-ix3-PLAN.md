    - `_build_source_block(stats, prev, extra, now) -> dict[str, Any]`: pure function. Builds new_block from stats (last_run, docs_processed, last_failure/last_success preservation logic), merges non-reserved keys from extra, and — for source 'enrich' only — populates alert_level if missing. Note: caller passes source name implicitly by deciding whether to invoke alert_level path. Cleanest split: keep the `if source == "enrich"` branch in `record_source_run` after `_build_source_block` returns, OR pass `source` as a parameter to `_build_source_block`. Prefer passing `source` as parameter so alert merge stays inside the pure builder (still pure: same inputs → same output).
    - `compute_enrich_alert_level`: collect contributing levels into a list, then pick by priority. Priority order: `warn` > `info` > `None`. Implementation: build `levels: list[str] = []`, append candidates that trigger, then return `"warn" if "warn" in levels else "info" if "info" in levels else None`.
    - Remove both `.replace("Z", "+00:00")` calls and the try/except around fromisoformat. Python 3.12 fromisoformat handles `Z`. Keep a narrow try/except only if needed for genuinely malformed strings — but per the description, "direct fromisoformat is sufficient", so drop the try/except entirely. If `last_run` is not a string the existing `isinstance(last_run, str)` guard already prevents the call.

    1. Add new helper `_write_meta(path: Path, meta: dict[str, Any]) -> None` after `_atomic_write`:
       ```python
       def _write_meta(path: Path, meta: dict[str, Any]) -> None:
           """Serialize meta as YAML frontmatter + HEARTBEAT_BODY and write atomically."""
           yaml_text = yaml.safe_dump(meta, sort_keys=True, allow_unicode=True)
           content = f"---\n{yaml_text}---\n{HEARTBEAT_BODY}"
           _atomic_write(path, content)
       ```

    2. Add new pure helper `_build_source_block(source: str, stats: dict[str, Any], prev: dict[str, Any], extra: dict[str, Any] | None, now: str) -> dict[str, Any]` containing the block-construction logic currently inlined in `record_source_run` (lines ~125-153 in current file). Move the `if source == "enrich" and "alert_level" not in new_block:` branch inside this builder so the function is the single place that shapes a source block. Function must NOT do any IO and must NOT mutate `prev` or `stats` (read-only).

    3. Rewrite `record_source_run` body to:
       ```python
       path = heartbeat_path if heartbeat_path is not None else HEARTBEAT_PATH_DEFAULT
       meta = read_sources(path)
       sources = meta.get("sources")
       if not isinstance(sources, dict):
           sources = {}
       prev = sources.get(source)
       if not isinstance(prev, dict):
           prev = {}
       now = _now_iso()
       new_block = _build_source_block(source, stats, prev, extra, now)
       sources[source] = new_block
       meta["sources"] = sources
       _write_meta(path, meta)
       ```

    4. Rewrite `write_disk_section` body to use `_write_meta`:
       ```python
       path = heartbeat_path if heartbeat_path is not None else HEARTBEAT_PATH_DEFAULT
       meta = read_sources(path)
       meta["disk"] = dict(disk)  # shallow copy
       _write_meta(path, meta)
       ```

    5. Refactor `compute_enrich_alert_level` to be order-independent. Replace the sequential `level = "info"; ... level = "warn"; ...` pattern with:
       ```python
       levels: list[str] = []
       extra = extra or {}
       cf = int(extra.get("consecutive_failures", 0))
       backlog = int(extra.get("backlog_count", 0))
       processed = int(extra.get("docs_processed", 0))
       flagged = int(extra.get("docs_review_flagged", 0))

       if processed > 0 and (flagged / processed) > 0.10:
           levels.append("info")
       if cf >= 2:
           levels.append("warn")
       if backlog > 50:
           levels.append("warn")

       if prior_block and now_iso:
           last_run = prior_block.get("last_run")
           if isinstance(last_run, str):
               lr = datetime.fromisoformat(last_run)
               now = datetime.fromisoformat(now_iso)
               if (now - lr).total_seconds() > 26 * 3600:
                   levels.append("warn")

       if "warn" in levels:
           return "warn"
       if "info" in levels:
           return "info"
       return None
       ```
       Note: Drop both `.replace("Z", "+00:00")` calls and drop the surrounding `try/except (ValueError, TypeError)`. Python 3.12 `datetime.fromisoformat` natively accepts `Z`. The `isinstance(last_run, str)` guard remains; if the string is malformed, fromisoformat will raise ValueError — that's acceptable since stored last_run is always written by `_now_iso` which produces a valid ISO 8601 string.
