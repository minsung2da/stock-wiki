<objective>
Fix two DART collector bugs root-caused during a live 201-company GICS DART
collection.

BUG 1 — KRX's new-style 6-char alphanumeric short codes (e.g. "0001A0" for
덕양에너젠) are rejected by the `^[0-9]{6}$` ticker guard, blocking every
filing/entity write for any new-style-ticker company.

BUG 2 — OpenDART's document.xml endpoint, under sustained access, replies HTTP
200 with a `<status>020</status>` rate-limit envelope. `fetch_body` raises a
non-retryable `DartDocumentError` on it, so throttled filings fail permanently
in a dense run (5 filings were lost in the live run; they succeeded on a spaced
retry).

Purpose: unblock collection of new-style-ticker companies and make dense DART
runs resilient to API throttling — both are correctness bugs, not enhancements.
Output: widened ticker guard across the six enumerated collector/entity write
paths; a retryable throttle exception wired into the existing tenacity retry;
unit tests for both fixes; green regression on collectors + db.
</objective>
