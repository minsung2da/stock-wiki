| Threat | Disposition | Mitigation |
|---|---|---|
| SQL injection / unauthorized writes | mitigate | Fixed dataset/column allowlists, bound parameters, read-only transactions, no mutation routes |
| Stored script execution | mitigate | Render database strings using textContent, never raw HTML |
| Cross-site access to localhost data | mitigate | Loopback binding, Host/Origin validation, no CORS |
| Excessive reads / leaked errors | mitigate | Bounded page sizes, statement timeouts, sanitized errors |
</threat_model>
