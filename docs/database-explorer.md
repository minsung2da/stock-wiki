# DB 데이터 탐색기

저장된 데이터 종류와 건수를 확인하고 검색 결과의 전체 본문·수치·구조화 결과를
브라우저에서 조회하는 로컬 도구입니다. 외부 API 수집이나 분석을 실행하지 않습니다.

## 실행

PowerShell에서 프로젝트 루트 기준으로 실행합니다.

```powershell
Set-Location C:\Users\minsu\workspace\stock
.\.venv\Scripts\python.exe -m db.explorer
```

브라우저에서 <http://127.0.0.1:8766>을 엽니다. 종료는 실행 창에서 `Ctrl+C`입니다.
포트가 사용 중이면 `--port 8767`로 실행하고 해당 포트에 접속합니다.
프로젝트 `.env`의 `DATABASE_URL`을 사용하며 이미 지정된 환경변수가 우선합니다.
PostgreSQL이 실행 중이고 migration `0012`까지 적용되어 있어야 합니다.

## 검색과 상세 보기

왼쪽에서 데이터 종류를 고른 뒤 검색어·종목코드·날짜를 입력하고 **검색**을 누릅니다.
기본 검색어는 제목·식별자 등 해당 데이터의 설명 필드와 연결된 기업명에서 부분 일치로 찾습니다.
**본문 포함**을 선택하면 공시·뉴스·카드·메모의 저장된 본문도 검색합니다. 대용량 공시의
성능을 위해 본문은 영문 대소문자를 구분하고, 제목과 기업명 등은 구분하지 않습니다.
본문 검색은 종목·날짜로 범위를 좁히면 더 빠릅니다.
`%`와 `_`는 검색 연산자가 아닌 문자 그대로 처리합니다. 별도의 의미 기반 AI 검색은 아닙니다.

- 조건은 AND로 결합합니다. 예: 공시 + 기업명 `삼성전자` + 종목코드 `005930`.
- 종목코드는 6자리 대문자·숫자입니다. 뉴스는 관련 종목 배열에서 찾습니다.
- 날짜는 한국시간 기준이며 시작일과 종료일을 모두 포함합니다.
- 데이터별 날짜 기준은 아래 표와 화면에 표시됩니다. 기업 정보에는 날짜 필터가 없습니다.
- 25·50·100개씩 페이지를 이동합니다. 기본은 최신 날짜순입니다.
- 정렬 가능한 열 제목을 누르면 오름차순(▲), 다시 누르면 내림차순(▼)으로 바뀝니다.
  **재무지표 → PER 또는 PBR**을 눌러 배수 순으로 비교할 수 있습니다. 현재 페이지가 아닌
  전체 검색 결과를 DB에서 정렬하며, 숫자는 수치 기준으로 비교하고 값이 없는 항목은 항상 마지막에 둡니다.
  같은 값은 고정된 키 순서를 사용합니다. 저장된 0은 누락값으로 바꾸지 않고 숫자 0으로 정렬합니다.
- 정렬을 바꾸면 첫 페이지로 이동하며 검색 조건은 유지합니다. 페이지 이동·페이지 크기 변경에도
  선택한 정렬을 유지하고, 데이터 종류 변경 또는 **초기화** 시 기본 정렬로 돌아갑니다.
- **보기**를 누르면 저장된 전체 본문과 모든 공개 필드를 확인합니다. 뉴스 본문은 수집기가
  실제로 저장한 분량이며, 원문 사이트 전체 기사와 다를 수 있습니다.
- NUMERIC 값은 소수 자릿수를 보존합니다. 재무지표 상세에는 배당수익률과 DPS도 표시됩니다.
- 재무지표의 **ROE(연간 %)**는 DART 공식 주요 재무지표의 전년도 사업보고서 값입니다.
  2026년 수집은 2025년 연간 값을 조회합니다. 분기·반기 값이나 EPS/BPS 추정치와 섞지 않습니다.
  **ROE 결산일**을 함께 표시하며 ROE·결산일 모두 열 제목으로 정렬할 수 있습니다.
  DB/API의 ROE는 비율(`0.107830`), 화면은 백분율(`10.783%`)입니다. 음수·0은 그대로 표시합니다.
  공식 값이 제공되지 않으면 `—`로 남기고 상세에서 출처와 ROE 조회시각을 확인합니다.
- 기존 재무지표 행을 ROE로 보충해도 PER/PBR/EPS/BPS/배당/기존 출처·조회시각은 보존합니다.
  표의 **기준일**은 기존 시세 지표의 날짜이고, ROE의 결산일·조회시각은 별도입니다.
  현재 DART 응답으로 보충한 값은 과거 기준일 당시의 공시 상태를 재현한 데이터가 아닙니다.
- **새로고침**은 DB 저장 건수와 검색 결과를 다시 읽습니다. 실시간 시세 조회는 아닙니다.

| 화면 | 테이블 | 날짜 기준 |
|---|---|---|
| 공시 | `filings` | `filed_at` |
| 뉴스 | `news` | `published_at` |
| 시세·수급 | `ohlcv` | `trade_date` |
| 재무지표 | `fundamentals` | `fdate` |
| 매크로 | `macro_series` | `obs_date` |
| 근거 카드·브리핑 | `decision_cards` | `generated_at` |
| 기업 | `entities` | 없음 |
| 기업 별칭 | `entity_aliases` | `valid_from` |
| 메모 | `notes` | `updated_at` |
| 수집 실행 기록 | `collector_runs` | `run_at` |

전체 저장 레코드 수는 위 10개 테이블의 합계입니다. 내부 검색 인덱스, 과거 문서 파이프라인
테이블, 폐기된 위험 이벤트 테이블은 조회 대상에서 제외합니다. 저장 건수 `0`은 정상적인
빈 데이터입니다. DB 연결·스키마·조회 시간 초과 오류는 별도 오류 메시지로 표시합니다.

## 조회 전용 경계

서비스는 `127.0.0.1`에만 바인딩합니다. 허용된 Host/Origin만 받으며 CORS를 열지 않습니다.
HTTP GET으로 명시된 테이블과 필드만 읽고 요청값은 SQL 바인드 파라미터로 전달합니다.
모든 DB 조회는 `READ ONLY` 트랜잭션에서 실행하며 SQL 입력·수정·삭제 API는 없습니다.
페이지당 최대 100개, 일반 SQL 5초·본문 포함 SQL 30초 제한을 적용합니다. 데이터 원문은 HTML로 실행하지 않고
텍스트로 표시합니다. 이 로컬 도구에는 사용자 로그인 기능이 없으므로 외부 프록시로
공개하는 구성은 지원하지 않습니다.

API는 `/api/inventory`, `/api/search`, `/api/detail`입니다. 상세 키는 검색 결과의
`_key` 값을 URL 인코딩해 전달합니다. DB 접속정보와 SQL 오류 원문은 응답에 넣지 않습니다.

## ROE 수집

일반 `collect fundamentals`와 `collect all`에서 ROE를 수집합니다. KRX 응답이 비거나
오류가 나도 기업 코드가 있으면 DART ROE 조회를 별도로 수행합니다. 기존 ROE는 API 오류나
누락 응답으로 지우지 않습니다. 반복 조회가 동일하면 저장을 생략합니다.

기존 특정 날짜의 포트폴리오 재무지표만 보충하려면 다음을 실행합니다.

```powershell
.\.venv\Scripts\python.exe scripts/backfill_roe.py --date 2026-09-23
```

결과·누락 기업·다른 지표의 변경 여부는 `notes/private/roe-backfill-2026-09-23.json`에 남깁니다.
API 키는 `.env`의 `DART_API_KEY`를 사용하며 출처 URL에는 키를 저장하지 않습니다.
출처: [DART 단일회사 주요 재무지표 API](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2022001),
사업보고서 `11011`, 수익성 `M210000`, ROE `M211550`.

## 검증

```powershell
.\.venv\Scripts\python.exe -m pytest tests/db/test_explorer.py -q
.\.venv\Scripts\python.exe -m ruff check src/db/explorer.py tests/db/test_explorer.py
.\.venv\Scripts\python.exe -m mypy -p db.explorer --follow-imports=silent
```

DB 테스트는 testcontainers의 별도 PostgreSQL에서 실행합니다. 실제 사용자 DB를 지우거나
테스트 데이터를 넣지 않습니다. 한국시간 날짜 경계, 기업명·종목·본문 검색, 페이지 분리,
원문·수치 정밀도, 전체 조회 스키마, 읽기 전용 강제 및 HTTP 접근 경계를 검증합니다.
